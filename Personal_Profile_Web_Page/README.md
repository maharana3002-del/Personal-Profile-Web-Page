# Personal Profile Web Page

## Files
- `index.html` — profile page structure
- `style.css` — styling and responsive layout

## Run the project
1. Open this folder in Visual Studio Code.
2. Open `index.html` in a browser, or use the Live Server extension.
3. Replace `your-email@example.com` in `index.html` with your own email address before taking the final screenshot.

## Git commands
Run these commands in the project folder:
```bash
git init
git status
git add .
git commit -m "Create personal profile web page"
```

Create an empty repository on GitHub (do not add a README if you already have these files), then use the repository URL shown by GitHub:
```bash
git branch -M main
git remote add origin https://github.com/maharana3002-del/Personal-Profile-Web-Page
git push -u origin main
```
